Проект интеграции

1С Документооборот ↔ 1С ЗУП

Отправка и получение данных через веб-сервис. Структура проекта оформлена как современная презентация в стиле Bootstrap.

Формат
Bootstrap 5

Цель проекта

Автоматизировать передачу данных между 1С Документооборот и 1С ЗУП, чтобы руководители отделов, директоры департаментов, ответственный сотрудник и бухгалтерия работали с едиными и актуальными данными.

  • Моделирование потоков документов и данных
  • Формирование спецификации обмена (форматы, частота, ошибки)

  • Архитектура веб-сервиса (REST/SOAP, безопасность, логирование)
  • Реализация методов приёма/передачи данных
  • Настройка аутентификации и токенов доступа

  • Разработка клиентского кода в Документообороте для отправки данных
  • Создание формы ввода для руководителей отделов
  • Настройка согласования с директором департамента

  • Разработка кода приёма данных в ЗУП
  • Реализация загрузки данных в регистры ЗУП
  • Формирование отчёта для руководителей и директоров

  • Написание тестовых сценариев (аналитики)
  • Проведение тестов и исправление ошибок (разработчики)
  • Проверка корректности расчётов в ЗУП

  • Создание технической документации (разработчики)
  • Подготовка пользовательских инструкций (аналитики)
  • Проведение тренингов для руководителей и директоров

Уровень 3: Задачи исполнителей

1. Анализ бизнес-процесса и требований

Аналитик
  • Провести интервью с руководителями отделов и директорами департамента
  • Создать BPMN-модель процесса согласования и передачи данных
Разработчик
  • Проанализировать текущие конфигурации Документооборот и ЗУП на возможность расширения

2. Разработка веб-сервиса для обмена данными

Разработчик
  • Выбрать архитектуру веб-сервиса (REST vs SOAP) и оформить техническое решение
  • Реализовать метод PostData() для приёма данных из Документооборота
  • Реализовать метод GetData() для передачи данных в ЗУП
  • Настроить JWT-аутентификацию и логирование запросов
Аналитик
  • Определить требования к безопасности и логированию

3. Интеграция 1С Документооборот с веб-сервисом

Разработчик
  • Создать HTTP-обработчик в Документообороте для отправки данных
  • Реализовать форму ввода данных для руководителя отдела
  • Настроить событие «На согласование» для передачи директору
Аналитик
  • Определить правила согласования и маршрут документооборота к директору департамента

4. Интеграция 1С ЗУП с веб-сервисом

Разработчик
  • Создать HTTP-обработчик в ЗУП для приёма данных
  • Реализовать загрузку данных в регистры ЗУП
  • Создать отчёт в ЗУП с фактическими данными расчёта
Аналитик
  • Оформить спецификацию отчёта для руководителей и директоров

5. Тестирование и доработка обмена

Аналитик
  • Написать тестовые сценарии (входные данные, ожидаемый результат)
Разработчик
  • Провести модульное тестирование веб-сервиса
  • Провести интеграционное тестирование
  • Исправить ошибки обмена
Контроль качества
  • Проверка корректности расчётов в ЗУП

6. Документирование и обучение пользователей

Разработчик
  • Создать техническую документацию по веб-сервису
Аналитик
  • Подготовить пользовательскую инструкцию для руководителей отделов
Обучение
  • Проведение тренингов для руководителей и директоров
